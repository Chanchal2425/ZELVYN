LearnMate AI - Real-Time Collaborative Learning Workspace

A full-stack collaborative learning workspace that combines an AI learning assistant with real-time shared rooms, live notes, live chat, shared resources, task management, collaborative study sessions, and a shared Pomodoro timer.

The Challenge

Learning and group study often require multiple separate tools for notes, communication, resources, task tracking, study sessions, and asking questions. LearnMate AI was built as a single collaborative workspace where learners can work together inside shared rooms while also using an AI assistant.

Our Architectural Approach

LearnMate AI uses React for the frontend and Django for the backend. Django REST Framework handles standard API communication, while Django Channels manages WebSocket connections for real-time collaboration.

Redis is used as the channel layer for Django Channels, allowing WebSocket events to be distributed through shared room groups.

JWT authentication is used for authenticated application communication, while Google Sign-In provides an additional authentication method for users.

Real-Time Collaboration

Real-time communication is one of the core parts of LearnMate AI. Instead of requiring users to repeatedly refresh or request new data, supported collaborative features use persistent WebSocket connections.

Django Channels manages these connections using asynchronous WebSocket consumers. Users connected to the same room can receive relevant updates through room-based channel groups.

Redis provides the channel layer used to distribute these events between the WebSocket consumers.

Key Features Engineered

  • AI Learning Assistant: LearnMate AI includes an AI chatbot powered through the Grok API, allowing users to ask questions and receive AI-assisted learning responses.
  • AI Assistance for Shared Resources: Users can interact with the AI assistant about uploaded learning resources, making the shared resource library part of the learning workflow.
  • Live Collaborative Chat: Room members can communicate through live chat using WebSocket-based communication.
  • Live Shared Notes: Multiple users can work on shared room notes while updates are communicated through WebSockets. Update throttling and a fallback debounce mechanism help control continuous typing updates.
  • Live Shared Resource Library: Users can upload files and add external links, categorize resources, react to resources, comment, pin items, and remove resources according to the available permissions.
  • Shared Task Management: Learners can manage tasks within the collaborative learning workspace.
  • Shared Pomodoro Timer: The workspace includes a shared study timer whose state is synchronized through WebSocket communication. The session administrator controls the timer while other participants can observe the current state.
  • Collaborative Whiteboard: Provides a shared visual workspace for learners working together inside a room.
  • Live Presence & Typing Indicators: The workspace provides visibility into active users, including profile information and typing/activity indicators.

Authentication & User Access

LearnMate AI supports JWT-based authentication for authenticated application communication and also provides Google Sign-In as an authentication method.

The frontend maintains authentication information locally, while authenticated API requests use Bearer access tokens through the Axios client.

WebSocket connections also carry authentication information during connection establishment, allowing the backend to validate the user before accepting real-time communication.

AI Integration

The AI functionality is integrated into the learning workspace through the Grok API. The frontend communicates with the backend through the application's API layer, while the backend handles the AI-related request flow.

A key part of the learning experience is connecting AI assistance with shared learning resources, allowing users to ask questions about resources they have uploaded rather than treating the chatbot as a completely separate feature.

Frontend State Management

The React application uses Hooks such as useState, useEffect, useRef, and useCallback across the workspace components.

State is used for UI values, loaded application data, timers, WebSocket references, comments, resources, and other interactive workspace functionality.

React Context is also used for shared application functionality such as theme management.

Handling Continuous Updates

Collaborative editing can produce many updates while a user is typing. LearnMate AI uses throttling to limit outgoing updates during continuous typing and a fallback debounce mechanism to capture the final state after typing stops.

The shared notes implementation also preserves the user's caret position when remote content is applied, helping prevent unexpected cursor movement during collaboration.

Engineered Outcome

LearnMate AI brings AI assistance and collaborative learning workflows into one workspace. Users can communicate through live chat, work together on shared notes and visual collaboration features, exchange learning resources, use a shared study timer, manage tasks, and interact with an AI assistant within the same learning environment.

The combination of React, Django REST APIs, Django Channels, WebSockets, Redis, JWT authentication, Google Sign-In, and the Grok API provides the technical foundation for the application's collaborative and AI-assisted learning experience.
