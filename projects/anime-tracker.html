The Challenge

Anime fans often need multiple platforms to search for anime, maintain watchlists, track episodes, record ratings, and keep notes. The goal was to bring these workflows into one centralized application.

User Journey

01 - Sign In

User authenticates using Google Single Sign-On.

02 - Discover

Search the anime catalogue and discover new titles.

03 - Track

Add anime to the watchlist and track episode progress.

04 - Remember

Attach notes and timestamps to specific episodes and memorable scenes.

05 - Discover More

Receive personalized, similar, and scenario-based recommendations.

06 - Share

Share selected anime content and scene references through public URLs.

07 - Connect

Join the community, publish thoughts, edit posts, delete posts, and interact with other users.

Our Architectural Approach

The application was structured as a React frontend communicating with a Django REST Framework backend. Anime discovery is powered by the Jikan API, while user-specific watchlist information, progress, notes, and viewing data are stored in the application's database.

Key Features Engineered

  • Anime Discovery: Search anime using the Jikan API and display titles, posters, episode counts, ratings, and genres.
  • Personal Watchlist: Add anime to a personal watchlist, view saved titles, and remove entries.
  • Episode Progress: Track current episode, total episodes, and watch status.
  • Episode Notes: Save notes against individual episodes for future reference.
  • Viewing Statistics: Calculate completed anime, watching status, episodes watched, watch time, ratings, and viewing streaks.
  • Recommendations: Generate recommendations based on genres already present in the user's watchlist.

Technology Stack

React.js Django Django REST Framework SQLite Jikan API JavaScript REST API

Backend Engineering

The Django backend provides REST endpoints for anime entries, episode notes, watch logs, statistics, anime search, similar anime, and recommendation functionality.

The backend also separates anime data belonging to the application's user and manages relationships between anime entries, episode notes, and watch logs.

Frontend Engineering

The React frontend consumes the REST API and provides an interactive interface for searching anime, adding titles to the watchlist, displaying saved anime, updating progress, and presenting statistics.

Engineered Outcome

The result is a full-stack anime ecosystem that combines discovery, personal tracking, contextual recommendations, timestamped episode notes, scene-based sharing, authentication, analytics, and community interaction within a single platform.

Instead of functioning as only a watchlist, the application creates a complete workflow around anime consumption: users can discover a title, save it, track their progress, document specific moments, receive recommendations, share content, and participate in a community.
